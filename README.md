# O T6 joga sem burca ⚽

Joguinho de navegador do time de futebol feminino T6: atravesse o campo, desvie dos zagueiros de terno e dos projetos de lei, e marque o gol contra o Senador do Retrocesso pra tirar a burca de vez.

## Como jogar
- **Celular** (na horizontal): joystick para mover, botão para chutar.
- **Computador:** setas ou WASD para mover, espaço para chutar.

## Elenco
3, Lígia, Gabi, Isabella, Blue, Bruna, Day, Maressa, Gi, Beatriz, Laiz e Alê, com a técnica Tainá na lateral.

## Publicar no GitHub Pages
1. Suba estes arquivos num repositório público.
2. Vá em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)` e salve.
3. Em 1 ou 2 minutos o jogo fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

O jogo inteiro está no `index.html` (o escudo já vai embutido). A música e os efeitos são gerados no próprio navegador.
